# metadata-proyekt-sokmotor

Node.js project scaffold for a metadata search backend.

## Project Structure

- `backend/src/` - backend source files
- `sql/schema.sql` - database schema
- `sql/seed.sql` - seed data placeholder

## Setup

Install dependencies:

```bash
npm install
```

Create a local `.env` file for environment-specific settings. Do not commit `.env` to GitHub.
